# SAM / GRU 阶段实验协议

本阶段基于 [UEVAVD arXiv v1](https://arxiv.org/html/2411.04348v1) III-B 与 IV-A，在上一阶段 [环境协议](../map_baseline/PROTOCOL.md) 上加入场景分解和观察历史。原 MAP checkpoint、分类器、原图缓存与旧结果保留。

## 实验矩阵

| 策略 | 策略图像输入 | 历史信息 |
|---|---|---|
| MAP | 原始 RGB | 当前观察 |
| Memo-MAP | 原始 RGB | GRU |
| SAM-MAP（本次额外消融） | SAM 分解 RGB | 当前观察 |
| IBE-MAP | SAM 分解 RGB | GRU |
| 扫描 / 随机 | 原始观察的固定分类器分数 | 沿用上一阶段的访问记录与停止规则 |

SAM 改变的是策略的图像输入。所有策略使用**完全相同的原图车辆分类器输出**计算识别准确率和奖励；不会把 SAM 处理图送给识别分类器后再与原图基线混合比较。

沿用100/25/25场景划分、每场景全部605起点、25个合法动作、最多5次决策、gamma0.9、终止奖励±0.5、非终止惩罚0.1、每10m惩罚0.02、同一个成功条件。原生停止与固定三次移动诊断分别报告。固定三次移动控制的是次数，不是相同米数预算。

## SAM 场景分解

原文要求：使用部分训练数据微调 SAM；以目标 bbox 提示分割目标，再用目标轮廓外一圈采样点分割周围地物；保留目标 RGB，将周围物体替换为随机灰度。

**本地公开数据副本没有像素级分割 GT，也没有作者微调后的 SAM 权重。因此当前运行使用 Meta 官方预训练 SAM ViT-B，未复现原文的 SAM 微调步骤。** 不使用 bbox 矩形、普通灰度化或传统图像分割冒充 SAM。所有目标和周围物体掩码来自实际 SAM 推理。

可复查实现：

- 从 [Meta 官方仓库](https://github.com/facebookresearch/segment-anything) 下载固定 commit 的模型源码，保留 LICENSE；源码清单与 hash 在 `third_party/segment_anything/SOURCE.json`。仅改顶层导入，避免加载本流程不需要的 torchvision NMS；模型文件保持原样。
- 使用官方 `sam_vit_b_01ec64.pth`，来源和完整 SHA256 记入权重旁 JSON。ViT-B 是本次可运行版本的选择，原文没有明确 SAM 变体。
- 输入256×256 RGB按官方尺寸放大至1024×1024，ImageNet风格归一化；bbox/点坐标相应乘4。图像编码器CUDA float16 autocast，提示与掩码解码器float32。
- 推理将上游注意力的相同Q/K/V与分解相对位置偏置交给PyTorch SDPA执行，减少中间矩阵开销；这是数学等价的内核替换，经过带非零位置偏置的float32数值比较，混合精度下不宣称逐位一致。官方模型源码文件未改，适配代码与hash单独记录。
- 掩码解码按“每个提示配对自己的图像嵌入”批处理，保持上游解码公式，先选最佳低分辨率mask再执行原后处理。真实4张图的bbox掩码与逐图上游解码完全一致；32个点提示中有5个像素的浮点舍入差异，最小mask IoU为0.999945。没有改变采样点或候选选择规则来换取速度。

上述IoU仅检验批处理实现与上游输出的一致性，**不是对真实分割标注的准确率**。缺少像素GT，因此没有报告目标分割的定量性能。
- 目标bbox使用single-mask输出。没有可见目标bbox时，目标mask为空；不会凭空补出目标RGB。
- 取8个等角度径向方向，沿预测目标mask到最外边缘，再向外12像素放置点提示。跳过落在目标内或重复的点；缺少有效mask时使用bbox外椭圆，空bbox则在图像中心半径32处采样。这些是原文未公开的具体参数。
- 每个周围点独立作为前景提示；取SAM三个候选中预测IoU最高的mask。大的mask先填、小的后填，最后恢复预测目标mask内的原始RGB；未分割区域保留RGB。
- 每个mask随机灰度为0…255，随机数由当前图像内容hash和种子42确定；不使用场景编号、车型标签或测试奖励。缓存的同一观察灰度固定，未复现逐训练访问重新随机化的潜在方案（原文未说明其随机化时序）。
- 分解图再经与基线相同的冻结ResNet50提取2048维特征。保留全部分解PNG、预览mask与提示点、各场景元数据。进度按批次保存，可续跑。

SAM权重、源码版本、本地处理代码、全部参数、原始数据指纹都进入新缓存身份；旧分类器概率直接从原缓存复制，不重新训练。评估必须检查原图与SAM缓存的positions、names、boxes、visible和probs一致。

## GRU 与因果训练

图像2048维特征经LayerNorm、Linear/ReLU得到512维，bbox经Linear/ReLU得到32维；拼接得到原文的 `g_t=544`。单层单向GRU的隐藏状态 `h_t=544`，投影后 `s_t=512`，其后沿用上一阶段的状态价值、方向优势、幅度优势分支。无GRU消融使用原MAP完全相同的网络结构。

每回合初始hidden为零，推理只输入到当前时刻的观察。行动时从当前回合起点重建最多5个观察的因果prefix，避免梯度更新之后使用旧网络产生的隐藏状态。结束回合只重置该环境对应历史。

Replay保持100,000条transition和均匀transition采样。每条transition保存从回合起点到next observation的完整prefix，取样时用当前online网络和target网络各自独立从零展开。当前Q使用当前时刻输出；DoubleDQN next action使用下一时刻online输出、next value使用target输出。每个样本只对当前transition计算一次loss，padding不产生loss，终止不bootstrap。不得用随机孤立帧训练GRU而丢弃历史，也不得把跨回合hidden混用。

保留Adam1e-4、batch256、64环境、每向量步一次更新、2048条转移warmup、epsilon1→0.05、target每500更新、SmoothL1、梯度裁剪10。每模型先使用原训练集内部90/10划分进行30,000回合开发验证，再重新初始化于全部100训练场景训练300,000回合；64个并行环境导致实际完成数可略超预算。full模型使用最终checkpoint，不按hard test挑选。各模型固定相同episode预算，但策略长度不同，因此transition与梯度更新总数可能不同，实际数量均记录。

## 结果解释边界

本阶段同条件比较可以检验当前实现中SAM场景分解和GRU记忆的作用，不能预设组合必然优于MAP。使用一个训练种子42，沿用上一阶段冻结视觉主干和自行定义的Q分支组合；尚未复现论文五训练种子统计、端到端视觉主干训练或SAM微调。bootstrap区间只描述场景间波动，不能替代多训练种子。

展示轨迹是事后选择的解释样例；总体结论须基于全部起点、准确率、路径长度与回报，并同时检查训练至hard test的泛化差距。原文与本地设定的剩余差异不因补入SAM/GRU而消失。
