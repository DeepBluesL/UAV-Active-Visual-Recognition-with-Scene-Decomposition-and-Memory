# 五随机种子与训练曲线阶段

本阶段继续补齐 [论文 IV-B](https://arxiv.org/html/2411.04348v1#S4.SS2) 的重复实验和泛化分析，在上一阶段相同环境、分类器、SAM 分解和冻结编码器上，分别重训 MAP、Memo-MAP、SAM-MAP、IBE-MAP。实验身份由 `output/ibe_multiseed/run_manifest.json` 固定，旧的单种子结果和缓存保留。

## hard split 五种子结果

表中学习策略的数值为五个训练种子的均值 ± 样本标准差（`ddof=1`）；准确率以百分比表示，距离以米表示。扫描和原地为确定性参考，因此标准差为0；随机策略的离散来自五个评估种子，不是训练种子。每种子每策略在25个 hard 场景的605个共同起点上评估，共15,125回合。

| 策略 | 准确率（%） | 平均回报 | 平均距离（m） |
|---|---:|---:|---:|
| 原地（stationary） | 76.89 ± 0.00 | 0.2689 ± 0.0000 | 0.00 ± 0.00 |
| 扫描（sweep） | **92.33 ± 0.00** | 0.2584 ± 0.0000 | 30.21 ± 0.00 |
| 随机（random） | 87.93 ± 0.14 | 0.2278 ± 0.0008 | 24.80 ± 0.14 |
| MAP | 89.11 ± 1.41 | 0.3247 ± 0.0049 | 11.03 ± 1.66 |
| Memo-MAP（GRU） | 88.96 ± 0.81 | **0.3290 ± 0.0034** | 9.97 ± 1.06 |
| SAM-MAP | 90.14 ± 0.81 | 0.3182 ± 0.0018 | 14.96 ± 0.95 |
| IBE-MAP（SAM+GRU） | 90.54 ± 0.93 | 0.3259 ± 0.0042 | 14.01 ± 1.42 |

IBE-MAP 是四种学习策略中平均准确率最高的（90.54%），扫描策略整体更高（92.33%）。四种学习策略中 GRU 的平均回报最高（0.3290）；IBE-MAP 相对 MAP 尚未显示出明确的回报优势。按相同训练种子配对计算的 IBE-MAP−MAP 准确率差为 +1.43 个百分点，95% t 区间 [+0.29, +2.56]；回报差为 +0.00124，区间 [−0.00372, +0.00619]，跨0。IBE-MAP−Memo-MAP 的准确率差为 +1.58 个百分点，区间 [−0.55, +3.71]；回报差为 −0.00308，区间 [−0.00956, +0.00339]，两项区间都跨0。IBE-MAP−SAM-MAP 的准确率差为 +0.40 个百分点，区间 [−1.20, +2.00]；回报差为 +0.00771，区间 [+0.00326, +0.01216]。这些配对区间来自五个训练种子的差值，**不是**按场景 bootstrap 的区间；样本数少且未作多重比较校正，解读限于当前固定场景、冻结分类器与 SAM 条件。

上一阶段单种子中 GRU 的准确率提升不应视为稳定结论：该种子里 Memo-MAP 曾高于 MAP，而五种子平均准确率为 Memo-MAP 88.96%、MAP 89.11%。两者配对准确率差为 −0.15 个百分点，95% 区间 [−2.85, +2.54]，跨0。此次结果既不支持单种子所见的 GRU 准确率优势，也不能证明 GRU 普遍降低准确率。

五种子训练共20个正式训练任务（4种学习策略 × 5种子），每任务请求300,000回合，实际合计完成6,000,364回合。独立摘要核验通过：440个训练曲线点；135组最终指标；3,630,000条轨迹、CSV行数和唯一回合键数一致。`run.log` 记录38项测试通过（`OK`），`summary.log` 记录核验 `passed: true`。统计明细见 `output/ibe_multiseed/summary.json`，核验结果见 `output/ibe_multiseed/summary_verification.json`，报告见 `output/ibe_multiseed/report.html`。

本阶段通过 `& 'E:\Code\UEVAVD\run_multiseed.ps1'` 运行。以下训练与曲线运行命令均由该脚本分阶段调度；完整参数、输出位置和解读限制见本页后续章节。

## 训练和评估

- 预先固定训练种子为 42、43、44、45、46；论文未公开具体种子编号，这五个编号是本实现选择。
- 四种学习策略各运行五次，每次 300,000 回合，共 20 次正式训练。沿用前阶段确定的超参数；不重复选参，不根据 hard 结果修改模型。每次从初始化开始，使用全部 100 个训练场景。并行环境可能使实际完成回合数略超预算，记录实际回合、转移和梯度更新数。
- 每次保存初始化模型，以及每 30,000 回合的模型，共 11 个检查点。所有 20 次训练完成后，才评估这些检查点。最后的 300,000 回合模型是唯一最终模型，不从测试曲线上挑选最好点。
- 曲线每点均对 100 个 train 场景及 25 个 hard 场景的全部 605 个起点评估；统计为贪心策略，不把训练时 epsilon 探索下的近期表现混入测试曲线。每模型同预算检查点跨种子对齐，实际完成数另存。
- 最终模型评估全部 train、simple、hard 场景，仍比较原地、扫描、随机、MAP、Memo-MAP、SAM-MAP、IBE-MAP，并保留 hard 固定三次移动诊断。每种子 726,000 条轨迹，五次完整评估共 3,630,000 条。
- 原地和扫描是确定性参考；重复计算结果必须一致，不把五份相同数值当五个独立训练样本。随机策略使用同一预先固定的五个评估种子，其方差是随机行动的方差。学习策略为贪心评估，其差异来自训练随机种子。

本阶段不重跑 SAM 和分类器：90,750 个 SAM 分解图及对应特征已在前阶段生成。缓存的文件哈希、观察身份和训练分割指纹会被核对。

## 统计口径

每个策略先在同一完整场景集内计算每个种子的指标，再对五个种子求均值和样本标准差（`ddof=1`）。均值的双侧 95% 区间为 `mean ± 2.776445105 × SD / sqrt(5)`，使用自由度 4 的 Student-t 分布；区间不截断。它描述固定场景、固定分类器和固定 SAM 条件下的训练随机性，不估计新场景或上游模型的波动。

模块消融对比先在相同种子内相减，再对五个差值计算上述区间。只对学习策略进行这种配对，不将随机策略的评估种子方差解释为训练种子方差。只有五个训练种子，且多项比较未进行多重检验校正，结果用于描述当前实现，不作普遍优越性声明。

`GenGap = train 平均回报 − hard 平均回报`。泛化差距较小须同时结合 hard 回报判断；单纯降低训练表现也会缩小差距。

论文使用滑动平均曲线，本阶段展示每个检查点的原始结果与跨种子区间，不进行平滑。检查点频率也是本实现的选择，论文未公开足以逐点对齐的完整 epoch 定义。

## 运行

```powershell
& 'E:\Code\UEVAVD\run_multiseed.ps1'
```

默认使用现有 `uav` Python 环境，先完成回归检查。已通过身份核验的完整训练和评估可复用；中断的训练任务重新初始化重训该任务，不冒充从优化器状态精确续训。变更预算、种子或训练实现时，应通过 `-Out` 指定新的目录。

```powershell
# 分步运行；曲线/最终评估均要求所有模型先训练完毕
.\run_multiseed.ps1 -Stage train
.\run_multiseed.ps1 -Stage curves
.\run_multiseed.ps1 -Stage final
.\run_multiseed.ps1 -Stage summarize

# 仅根据已经生成的 summary.json 重建图表和报告
.\run_multiseed.ps1 -Stage report
```

## 产物与复现差异

- `output/ibe_multiseed/report.html`：跨种子结果、配对差值、训练/测试曲线、泛化差距和逐种子轨迹入口。
- `summary.json`、`curves.json`：未经平滑的原始统计、均值/标准差/置信区间及检查点身份。
- `seed_<seed>/<policy>/train`：初始化及中间快照、最终模型和训练日志。
- `seed_<seed>/evaluation`：每个种子的全部指标、CSV、逐步轨迹、独立核验和示例动画。
- `run_manifest.json`：冻结的实验计划、训练源码及缓存哈希。
- `summary_verification.json`：正式 300k/30k 协议下的独立跨种子核验，以标准库重算统计、核对快照和每种子已验证的结果文件哈希。

本阶段仍使用官方预训练 SAM ViT-B，未微调 SAM；数据发布副本没有像素级目标分割标注或作者微调权重。ResNet50 特征编码器及既有 ResNet18 分类器冻结；Q 分支组合、GT bbox 和离散运动环境仍沿用本地实现。完成五种子实验不等于消除这些与原论文的差异，细节见 [SAM/GRU 协议](PROTOCOL.md)。
