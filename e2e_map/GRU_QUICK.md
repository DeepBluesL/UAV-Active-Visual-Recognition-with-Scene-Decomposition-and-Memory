# GRU 小规模端到端复现

2026-10-24 继续此前暂停的 SAM+GRU（IBE-MAP）端到端实验。本次只使用 **seed 42**，端到端主干与冻结主干各完成 **5,000 回合、176 次更新**，不恢复原五种子队列。两组共 **90,750 条轨迹通过独立核验**，详见 [GRU 短测报告](../docs/gru_quick_reference/README.md)。

| 方法 | Simple 准确率 | Hard 准确率 | Hard 回报 | Hard 距离 |
|---|---:|---:|---:|---:|
| 冻结主干 SAM+GRU | 86.45% | 85.42% | 0.2691 | 13.55 m |
| 端到端 SAM+GRU | 84.46% | 87.54% | 0.2849 | 12.58 m |

本轮端到端版在原生停止的 Hard 测试较好，但 Simple 较差，固定三步诊断也未改善，因此不能概括为稳定提升。四个 GRU 参数张量均实际更新；端到端主干各阶段均更新、BN 运行统计保持固定、AMP 跳过为 0。端到端训练循环约 122.44 秒，冻结策略头训练约 1.63 秒；后者复用预先生成的特征，不包含特征提取成本。

GRU 结构沿用论文的 `g=544、h=544、s=512`：单层单向 GRU 聚合历史观察，每回合从零状态开始；replay 记录完整因果前缀，online 与 target 分别重建状态。当前 Q 不读取 next observation 或 padding，梯度经过有效历史帧及视觉主干。结构和实验参数依据 [原论文 III-B、IV-A](https://arxiv.org/html/2411.04348v1)。

两组使用相同初始 GRU 权重、训练场景、BF16 图像编码精度、FP32 特征与策略头、Adam、batch256、64 个环境、奖励、动作空间和探索率日程；TF32 均关闭。冻结组复用已经核验的 BF16 特征，端到端组每次更新重新计算图像特征。SAM 使用现有官方预训练 ViT-B 分解结果，仍未复现论文的 SAM 微调。

GRU 的每条样本含多帧历史，因此这次保留整网激活重算、图像 microbatch=32。上一轮 MAP 关闭重算的速度结果不能直接外推到 GRU。

5,000 回合是独立短训练预算，探索率在前 70% 的短预算内从 1 降至 0.05。这不是原 300,000 回合训练的前 5,000 回合。配置中的 `phase=full` 仅表示使用全部 100 个训练场景，不表示完成论文的训练预算。

训练完成后，每组评估 simple、hard 和 hard 固定三步诊断，各覆盖 25 个场景 × 605 个起点，合计 **45,375 条轨迹/组**。独立核验器逐条检查动作、奖励、距离、识别和汇总指标。报告再核对初始/最终 checkpoint、四个 GRU 参数张量的更新、主干更新、固定 BN 统计以及 AMP 跳过数。

这里只比较同一 GRU 策略在主干可训练与冻结时的短预算表现；不单独识别 GRU 或 SAM 的贡献，也不把旧 MAP 的 300k 结果作为公平对照。一个 seed 不足以支持稳定改善或显著性结论。

```powershell
# 只运行一个种子的两组短训练及评估，要求独立的新输出目录。
python -m e2e_map.gru_quick --variant ibe_map --seeds 42 --episodes 5000 --out output/gru_quick_20261024

# 仅读取实际进度。
Get-Content output/gru_quick_20261024/status.json

# 所有训练/评估完成后，只重新核验并生成报告。
python -m e2e_map.gru_quick --variant ibe_map --seeds 42 --episodes 5000 --out output/gru_quick_20261024 --report-only
```

入口最多接受两个不同的 seed，预算限于 1,000–10,000 回合。选择 `--variant memo_map` 可在另一个新目录运行不含 SAM 的 GRU 版本，本次没有自动追加该实验。
